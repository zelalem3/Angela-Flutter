# 📱 Flutter Development

A collection of Flutter applications and hands-on projects built while learning cross-platform mobile development through **The Complete Flutter Development Bootcamp with Dart** by [Angela Yu](https://www.appbrewery.co/).

This repository documents my journey from Flutter and Dart fundamentals to building interactive mobile applications, working with APIs, managing application state, and exploring mobile app architecture.

The projects are organized into individual Flutter applications, each focusing on different concepts and practical development skills.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- [Android Studio](https://developer.android.com/studio) or [Visual Studio Code](https://code.visualstudio.com/)
- An Android emulator or a physical device.

### Clone the Repository

```bash
git clone https://github.com/zelalem3/Angela-Flutter.git

cd Angela-Flutter
```

### Run a Project

Each application is maintained in its own directory.

For example, to run the Dicee application:

```bash
cd dicee_flutter

flutter pub get

flutter run
```

To run another application, navigate to its respective directory and repeat the commands.
